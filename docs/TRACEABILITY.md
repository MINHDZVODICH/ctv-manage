# MA TRẬN TRUY VẾT YÊU CẦU (TRACEABILITY MATRIX)

Tài liệu này ánh xạ chi tiết các yêu cầu kỹ thuật và nghiệp vụ cốt lõi từ đặc tả (`plan.md`, `USE-CASE.md`) tới triển khai mã nguồn, ràng buộc cơ sở dữ liệu, giao diện frontend, bộ kiểm thử tự động và tài liệu kiến trúc/sơ đồ tương ứng.

## 2. Quy tắc duy trì ma trận truy vết (Traceability Invariants)

1. Mọi thay đổi về lược đồ cơ sở dữ liệu (`prisma/schema.prisma` hoặc file migrations) bắt buộc phải cập nhật đồng thời trong `DATABASE.md` và ma trận truy vết `TRACEABILITY.md`.
2. Mọi thay đổi về hợp đồng API (`app/backend/src/modules/*/routes.ts` hoặc DTOs) bắt buộc phải cập nhật đồng thời trong `API.md` và các sơ đồ tuần tự tương ứng.
3. Bộ kiểm thử E2E và Integration Tests là tiêu chuẩn nghiệm thu xác minh tính đúng đắn cho mọi yêu cầu trong bảng ma trận này.
